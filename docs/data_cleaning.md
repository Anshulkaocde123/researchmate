# QASPER Data Cleaning & Artifact Catalog

> **Dataset Scope:** Full scan of all 1,585 papers (81,502 paragraphs, 11,364 figures/tables, 12,761 ground-truth evidence items) across train, validation, and test splits.

---

## 1. Executive Summary

QASPER was generated by parsing raw LaTeX source and PDF files from arXiv. While this preserves full text structure, the extraction pipeline introduces special tokens, placeholder markers, unprocessed LaTeX commands, and whitespace irregularities.

For retrieval and generation:
1. **Citation & Reference noise degrades dense embeddings and sparse BM25 retrieval** because random IDs like `BIBREF14` or `TABREF2` pollute vocabulary frequencies and sentence semantics without providing semantic value.
2. **`FLOAT SELECTED:` prefixes in ground-truth evidence** reflect the annotator UI rather than the paper text itself.
3. **Stray LaTeX markup** (e.g. `\rm`, `\bf`, `\text{...}`) causes token fragmentation in subword tokenizers.
4. **Original raw text must be preserved alongside cleaned text** because QASPER's ground-truth evidence annotations contain verbatim substrings from the uncleaned papers. Discarding raw text would prevent exact or token-level evidence verification during evaluation.

## 3. Cleaning Strategy & Pipeline

`researchmate.data.cleaning.clean_text(text: str)` executes the following transformation passes in sequence:

1. **Evidence Prefix Stripping**:
   Strips `FLOAT SELECTED:` and `FLOAT SELECTED` (case-insensitive) from table/figure evidence annotations.
2. **Citation Token Removal**:
   Removes `BIBREF\d+` (and prefixed variants like `BERTBIBREF0`).
3. **Reference & Formula Placeholder Removal**:
   Removes `(SEC|TAB|FIG|EQ|UNK)REF\d*` and `(INLINE|DISPLAY)FORM\d*`.
4. **LaTeX Normalization**:
   - Unwraps display math `$$...$$` and inline math `$x$` into clean text representations.
   - Strips font formatting commands (`\rm`, `\bf`, `\it`, `\cal`, `\text{...}`, `\mathbf{...}`, `\mathit{...}`).
   - Normalizes math symbols (e.g. `\cdots` $\rightarrow$ `...`, `\pm` $\rightarrow$ `+/-`, `\leq` $\rightarrow$ `<=`).
   - Unescapes LaTeX characters (`\%` $\rightarrow$ `%`, `\&` $\rightarrow$ `&`, `\_` $\rightarrow$ `_`, `\$` $\rightarrow$ `$`).
   - Strips residual backslashes.
5. **Orphan Parentheses & Brackets Cleanup**:
   After removing citations, constructs like `(BIBREF1)` or `[BIBREF0, BIBREF2]` leave empty `()` or hanging `(, )`. These are cleanly removed or collapsed.
6. **Punctuation Normalization**:
   - Collapses duplicate commas/semicolons (`,,` $\rightarrow$ `,`).
   - Collapses double periods (`..` $\rightarrow$ `.`) while preserving valid ellipsis (`...`).
   - Removes spaces preceding punctuation (`word ,` $\rightarrow$ `word,`).
7. **Whitespace Normalization**:
   - Converts `\r`, `\n`, `\t` into single spaces.
   - Collapses multiple spaces into one.
   - Strips leading and trailing whitespace.

## 4. Preservation of Raw Text for Evidence Matching

In QASPER evaluation:
- Annotated evidence in `qas[*].answers[*].answer.evidence` contains raw paper snippets.
- If retrieval only indexes cleaned text, an exact string match against the ground-truth evidence might fail due to missing `BIBREF0` or altered whitespace.
- Therefore, each `Paragraph` in `researchmate.data.models` retains both:
  - `text`: the cleaned text used for chunking, embedding, BM25 indexing, and LLM prompting.
  - `raw_text`: the verbatim original string used for evaluation and evidence span matching.

---

## 5. Verification & Invariants

1. **Idempotency Invariant:**
   $$\forall x, \quad \text{clean\_text}(\text{clean\_text}(x)) = \text{clean\_text}(x)$$
   A cleaning function that is not idempotent can introduce compounding distortions when called multiple times.
2. **Non-destructive Semantics:**
   Cleaning removes non-lexical tokens and formatting noise without stripping actual prose or facts.
3. **Spot-check Validations:**
   Spot-checks across 10 random paragraphs with heavy artifacts verify that sentences retain natural English readability.
